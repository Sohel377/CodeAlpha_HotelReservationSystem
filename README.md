# CodeAlpha_HotelReservationSystem

## Overview
Hotel Reservation System is a Java console-based application developed using Object-Oriented Programming (OOP) concepts. The system allows users to search, book, and manage hotel rooms. It also supports reservation cancellation, payment simulation, booking details viewing, and file-based data storage.

## Features
- View all available hotel rooms
- Room categorization:
  - Standard
  - Deluxe
  - Suite
- Search rooms by category
- Book a room
- Cancel reservations
- View booking details
- Payment simulation
- File I/O for storing booking records
- Console-based user interface

## Technologies Used
- Java
- OOP Concepts
  - Classes and Objects
  - Encapsulation
  - ArrayList
- File Handling (FileReader, FileWriter, BufferedReader, BufferedWriter)

## Project Structure
- `Room` Class – Manages room information and availability.
- `Booking` Class – Stores booking details.
- `Hotel` Class – Handles room management, bookings, and file operations.
- `HotelReservationSystem` Class – Main class with menu-driven interface.

## How to Run
1. Install Java JDK.
2. Save the source code as `HotelReservationSystem.java`.
3. Compile the program:
   ```
   javac HotelReservationSystem.java
   ```
4. Run the program:
   ```
   java HotelReservationSystem
   ```
